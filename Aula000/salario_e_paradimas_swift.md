# Paradigma da linguagem Swift e Vaga encontrada

Swift não é um paradigma específico, mas sim uma linguagem que combina características de vários paradigmas, incluindo orientação a objetos e orientação a protocolos. Essa combinação permite que os desenvolvedores criem aplicativos robustos e eficientes, aproveitando a flexibilidade de uma linguagem orientada a objetos e a agilidade de uma linguagem orientada a protocolos.
